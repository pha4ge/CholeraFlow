Select an analysis mode

Each mode runs a curated pipeline tuned for a specific public-health question.

Quick guide

Outbreak Investigation answers: "Are these cases part of the same outbreak, and how is it spreading?"
Example: you've received 15 new isolates during an active outbreak — use Outbreak Investigation to see how closely related they are.
Routine Surveillance answers: "What strains and resistance patterns are circulating right now?"
Example: you're processing this month's batch of routine sentinel samples — use Routine Surveillance to track trends over time.
Source Attribution answers: "Where did this contamination most likely come from?"
Example: you have clinical isolates plus water or food samples from the same period — use Source Attribution to compare them.
You can change the mode later — nothing is locked in until you start the run.
